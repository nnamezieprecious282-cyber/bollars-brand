# BOLLARS BRAND

A premium streetwear e-commerce website built for Bollars Brand.

## About

Bollars Brand is a modern streetwear e-commerce platform designed to provide customers with a premium shopping experience across a range of streetwear products.

The project currently focuses on building a strong, scalable frontend architecture before connecting the application to a production backend.

## Current Features

* Product browsing and product details
* Product categories
* Shopping cart
* Wishlist
* Cart persistence
* Checkout system
* Customer and delivery information
* Nigerian state-based shipping
* Currency handling
* Checkout validation
* Order creation and persistence
* Duplicate-order protection
* Bank Transfer payments
* OPay payments
* Payment reference submission
* Payment receipt submission
* Payment verification status
* Order confirmation
* Admin foundation

## Payment Methods

The current checkout architecture supports:

* Bank Transfer
* OPay

Customer payment submissions are stored with an `awaiting_verification` status until payment verification is implemented through the backend/admin system.

## Technology

* HTML5
* CSS3
* Vanilla JavaScript
* LocalStorage

### Planned Backend

The production backend will introduce:

* Node.js
* PostgreSQL
* REST API
* Secure order and payment management
* Customer management
* Admin authentication
* Payment verification
* Persistent order data
* Administrative analytics

## Admin Dashboard

The admin system is planned to provide business insights and management tools including:

* Customer count
* Visitor count
* Best-selling products
* Order management
* Payment verification
* Product management
* Sales information
* Store configuration

## Project Status

**Current stage:** Frontend architecture and checkout system completed.

The next development stage is the backend and administrative system, followed by connecting the frontend to persistent server-side data.

## Disclaimer

This repository contains the ongoing development version of the Bollars Brand website. Features and architecture may change as development continues.
